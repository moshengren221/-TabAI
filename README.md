# 智识号-TabAI
智识号AITools，原生鸿蒙的ai api调用工具

**智识号AITools，您的随身AI助手。**

所有对话记录、API密钥、联系人配置等数据均存储在您的设备本地，加密保管。对话内容仅在您主动发送时加密传输至您所配置的AI服务提供商，我们不会上传、收集或共享您的任何个人信息。

**隐私承诺：**

多会话管理 — 支持创建多个独立对话会话，每个会话可配置不同的AI模型与系统提示词，满足学习、工作、创作等多场景需求
多模型兼容 — 兼容OpenAI、DeepSeek等主流AI模型接口，灵活配置，随心切换
上下文控制 — 手动标记重点消息加入上下文，精准控制AI的记忆范围，对话更高效
引用回复 — 引用AI的回复内容进行追问，让对话更有连贯性
AI简短想法 — 开启后AI会在回复中附带简短的想法表达，让对话更生动有趣
通知提醒 — AI回复完成后，即使不在聊天页面也能收到系统通知，点击即可快速回到对话
个性化定制 — 自定义聊天气泡颜色、AI昵称、联系人头像等，打造专属对话界面
核心功能：

智识号AITools是一款基于HarmonyOS平台打造的AI智能对话助手应用，为您提供高效、安全、个性化的AI对话体验。
